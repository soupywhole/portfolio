# usurawa.dev — сайт-портфолио

Отдельный проект. Файлы существующего сайта в родительской папке не меняются.

## Запуск

```powershell
cd W:\sites_present\usurawa-portfolio
npm.cmd run dev
```

Откройте **http://127.0.0.1:5174**. В PowerShell используется `npm.cmd`, чтобы не менять политику запуска скриптов Windows. В текущей рабочей папке используются уже установленные зависимости из родительского `node_modules`. Если переносите проект отдельно, сначала выполните `npm.cmd install`. Требуется Node.js 24+ для тестов TypeScript без дополнительных инструментов.

```powershell
npm.cmd run test
npm.cmd run lint
npm.cmd run build
```

## Что внутри

- Адаптивное портфолио: скульптурный первый экран с текстом поверх и матово-стеклянная навигация. По последнему запросу стекло продолжается до внешней скруглённой рамки: мягкое размытие фона, светлая полупрозрачная обводка и небольшой блик.
- Новая загрузка и обновление портфолио начинаются с самого верха: оставшийся якорь раздела удаляется до загрузки React. Переходы по разделам уже открытой страницы, история Назад/Вперёд и возврат из демо сохраняются. Прямые ссылки на демо не изменяются. Поздний сброс отменяется при первом действии посетителя, чтобы не мешать касанию или прокрутке во время загрузки шрифтов.
- Заголовки проявляются слева направо при прокрутке; написанный текст не исчезает при движении вверх.
- Карточки увеличиваются и занимают свои места без оранжевого маркера появления; на ПК мягко следуют за курсором, на телефоне наклоняются от касания и возвращаются после отпускания пальца. Обычная прокрутка и системные жесты не перехватываются. Движение скульптуры и фона работает и на сенсорных экранах; reduced motion остаётся статичным.
- На телефоне первые две работы портфолио стоят рядом, третья занимает следующий ряд целиком. В демо до 900 px — по две позиции в строке; до 600 px уменьшены отступы и изображения, кнопки сохраняют высоту не меньше 44 px. На широком экране остаются три позиции в строке.
- Два ненавязчивых градиентных пятна меняются местами и вращаются по прокрутке. При движении вверх эффект обратный; непрерывной фоновой анимации нет.
- FAQ и мобильное меню раскрываются с плавным появлением содержимого целиком, без побуквенного эффекта. Мобильная шторка остаётся в DOM и закрывается до нулевой высоты без скачка; скрытые ссылки отключены через `inert`. Стекло верхней рамки вынесено в отдельный декоративный слой и не перехватывает нажатия.
- Три интерактивных концепта: `#/demo/cafe`, `#/demo/repair`, `#/demo/tech`.
- В карточках портфолио — локальные снимки актуальных первых экранов этих демо, а не отдельные упрощённые макеты.
- Поиск, фильтры, подробные карточки; локальная демо-корзина для кафе и техники.
- fixpoint: фотографии iPhone и iPad в прежней композиции и мягкий обратимый 2D-поворот от прокрутки. Фото ремонта заполняет всю ширину от навигации до разделителя «Понятные услуги», с непрозрачностью 92% и короткими переходами сверху и снизу; светлая подложка только под текстом сохраняет читаемость.
- orbit: шесть локальных изображений устройств Apple, включая iPhone Duo и MacBook Air 15″ (2026), с фильтром «Ноутбуки». iPhone и AirPods Max в первом экране плавно выпрямляются при прокрутке первых 600 px; при движении вверх возвращается исходный наклон, при reduced motion движение отключено.
- Под каталогом fixpoint — широкий блок «Не нашли нужную услугу?» с временными личными контактами автора и явной пометкой о демонстрации.
- Настоящие контактные ссылки; никакой отправки заявок, оплаты, аналитики или серверной базы.
- Уменьшенные анимации при `prefers-reduced-motion`, клавиатурная навигация и нативные диалоги.

Контакты, цены и содержимое каталогов редактируются в **`src/data.ts`**. Telegram `@usurawarai` временный: **https://t.me/usurawarai**. ## Визуальное направление

Графитовый фон `#17171b`, мягкий белый `#faf9f7`, персиковый акцент `#f5dab8` и матовый голубой `#bdccd9`. Градиент согласован пользователем: `linear-gradient(180deg, rgb(255, 188, 188) 30%, rgb(245, 218, 184) 100%)`. На фоне он сильно приглушён, в небольших кнопках показан полностью.

Onest — основной текст и заголовки; Cormorant Garamond Italic — выразительные фрагменты; системный моноширинный шрифт — мелкие подписи. Manrope и собственные палитры трёх демо сохранены. Новое оформление находится в `src/portfolio.css`, эффекты — в `src/PortfolioEffects.tsx`; общие стили и иллюстрации устройств — в `src/styles.css`. Скульптура — локальная авторская SVG-иллюстрация, без 3D-движка и стороннего изображения.

Структура и характер движения вдохновлены референсом soulovev.ru, но оформление и код самостоятельные. Из UI/UX-каталога использованы рекомендации по иерархии, контрасту и статичному первому экрану при reduced motion. Точного совпадения для scroll-анимации React в каталоге не найдено после двух запросов: применены общие рекомендации и уже установленный Framer Motion. MCP 21st ранее использован только для визуальных ориентиров; платный код не покупался и не копировался.
